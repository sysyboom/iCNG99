# iCNG99
A validated genome-scale metabolic model (GEM) of *Cryptococcus neoformans* var. *grubii* H99.
# Overview
This repository contains the genome-scale metabolic model iCNG99, together with all scripts and datasets used for model reconstruction, validation, omics integration, and downstream analyses.
The repository is organized into three major sections:

- `model/` - genome-scale metabolic models and related files  
- `code/` - reconstruction, analysis, and visualization scripts  
- `data/` - transcriptomic, metabolomic, and validation datasets
